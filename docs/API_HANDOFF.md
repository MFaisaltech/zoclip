The implemented contract is [openapi.json](openapi.json), generated with
`uv run python scripts/export_openapi.py` from `zoclip.main.create_app` without
connecting to a provider or database. No future endpoints are included.
See [AUTH_HANDOFF.md](AUTH_HANDOFF.md) for request flow, cookies, CORS/CSRF,
disabled-service behavior and development email instructions.

Schemas: Me, Message, LoginResponse, CsrfResponse, SessionView, AuditView/AuditPage
and RFC7807-like Problem. Error content type is application/problem+json; validation
errors are sanitized rather than echoing passwords/tokens. UUIDs identify users and
sessions. UTC timestamps are generated by the application; database timezone should
be UTC. GET /me ignores any caller-supplied user ID and returns the session owner.
Foreign resource lookups use ownership in the SQL predicate and return 404.

Production disables interactive docs and OpenAPI HTTP routes. Keep generated
contract artifacts available privately to frontend developers. No frontend or
v0 production handoff is claimed in this phase. PATCH /me is deferred
because no editable profile fields were specified; email/password/role changes are
not exposed as an unrestricted profile update.

## Credits and plans

The generated OpenAPI includes these implemented routes. Cookie authentication
and verified active accounts apply to all /me routes. Customers cannot select an
owner ID. Ledger history excludes staff actors/reasons, operation keys and hashes.

| Method and path under /api/v1 | Contract |
|---|---|
| GET /plans | Public Free/Creator/Pro/Business/topup catalog, nullable price version, PKR integer paisa, approved flag, rules, no auto-renewal/credit expiry |
| GET /me/credits | WalletView: available_credits, reserved_credits; lazy zero wallet |
| GET /me/credit-transactions | TransactionPage: items, next_cursor; limit 1–100, UUID cursor |
| GET /me/entitlements | Bounded EntitlementView list; limit 1–100, exclusive UUID cursor; active flag; price_version_id pins rules |
| POST /jobs/quote | QuoteInput -> QuoteView; free calculation, idempotent, 15-minute expiry; not a job or enqueue |

QuoteInput fields are source_seconds (integer 1–7200), output_count (1–100),
edit_count (0–100, default 0), captions (default true), reframe (default true).
Plan limits may be smaller. QuoteView contains id, price_version_id, credits,
request and expires_at. No price/balance/deduction/user overrides are accepted.

POST requires Idempotency-Key (1–128 ASCII letters/digits/underscore/dot/colon/hyphen),
Origin and X-CSRF-Token. Credentialed CORS permits Idempotency-Key. Identical key
and payload return the same persisted result; reuse with changed payload returns
409 idempotency_conflict. An expired quote replay retains its original expiry;
use a new key for a fresh quote. Quote retries never charge. Later source/job routes
must revalidate advisory source duration and bind output/edit quotas to owned media.

## Staff configuration and metrics

Every staff route enforces server-side AdminUser, and service mutations recheck RBAC.
POSTs require CSRF, Idempotency-Key and a meaningful reason. Mutations and metrics
reads append immutable audit events. No customer grant/reserve/settle/refund endpoint
exists; job accounting is an internal transaction contract.

| Method and path under /api/v1 | Contract |
|---|---|
| POST /admin/plans/{plan_id}/versions | PlanVersionInput -> PriceView; immutable price, credits, validity, consumption rules, approved flag |
| POST /admin/users/{user_id}/credit-adjustments | AdjustmentInput -> TransactionView; signed nonzero integer adjustment, nonnegative result |
| POST /admin/users/{user_id}/entitlements | EntitlementInput -> EntitlementView; explicit manual award and exactly-once allowance, not payment verification |
| POST /admin/cost-rates | RateInput -> RateView; versioned model/unit/USD rate and max units |
| POST /admin/limits/versions | PolicyInput -> PolicyView; complete budgets/assumptions/rate IDs and breaker state |
| GET /admin/limits | Current PolicyView or null when unconfigured |
| GET /admin/usage-costs | Estimated, actual, held_or_unknown USD (decimal strings), attempt count |

Initial catalog price values and current policy are null. Price/rate/allowance
configuration is not seeded with invented commerce. No subscription auto-renewal,
checkout, payment verification or output endpoint is implied.
Automatic trials are disabled and cannot be toggled on until anti-abuse controls exist.
Use decimal strings for staff USD inputs; floats are rejected. See actual schema for
every required rule/limit field and [CREDITS_AND_MARGIN.md](CREDITS_AND_MARGIN.md) for
allowance lifecycle, quote math, lock order, refund semantics and worker integration.

Additional documented errors: 409 insufficient_credits, idempotency_conflict,
quote_expired, quote_stale, plan_limit, usage_limit, concurrency_limit,
reservation_exists/reservation_final; 503 plan_unconfigured, price_unapproved,
spending_disabled, rates_unconfigured, budget_exceeded, uncertain_spend,
accounting_mismatch. Phase 3 generation now consumes the internal reservation
contract and its admission errors; no payment or paid-provider endpoint is implied.

## Private ingestion and jobs

See [INGESTION_HANDOFF.md](INGESTION_HANDOFF.md) for complete request examples,
states, retries, capacity and operational limits. Actual generated DTOs are
UploadInput/UploadView, PartView, ImportInput, ProcessInput, JobView, EventView and
VideoView. Customer DTOs omit private paths, import URLs, worker tokens and payloads.

| Method/path under /api/v1 | Behavior |
|---|---|
| POST /uploads | Admit private bounded upload; idempotent |
| GET /uploads/{id} | Own session and received part numbers |
| PUT /uploads/{id}/parts/{number} | Stream exact-size binary chunk with X-Content-SHA256 |
| POST /uploads/{id}/complete | 202 durable async assembly/validation job |
| DELETE /uploads/{id} | Revoke source, cancel safely and schedule cleanup |
| POST /videos/import-url | 202 allowlisted, rights-attested direct HTTPS import |
| POST /videos/import-link | 202 rights-attested YouTube link import (yt-dlp subprocess, ≤1080p merge; proxy/PO-token via LINK_PROXY_URL / LINK_EXTRACTOR_ARGS) |
| GET /videos; GET /videos/{id} | Own retained assets and actual validated metadata |
| GET /videos/{id}/content | Owner-authorized private attachment; no public path/range |
| DELETE /videos/{id} | Immediate access revocation, lease-aware cleanup |
| POST /videos/{id}/generate | Canonical quote-bound atomic reservation/job/outbox; WAITING_ENGINE in Phase 3 |
| POST /jobs | Backward-compatible alias with video_id and quote_id; shared job idempotency namespace |
| GET /jobs; GET /jobs/{id} | Own durable states, attempts and heartbeat; null queue position |
| GET /jobs/{id}/events | Own immutable state events |
| POST /jobs/{id}/cancel | Idempotent cancellation; live worker acknowledgment before release |

CORS permits GET/POST/PUT/PATCH/DELETE and Content-Type, X-CSRF-Token,
Idempotency-Key, X-Content-SHA256 and If-Match. Every mutation needs Origin/CSRF
and an active verified session. JSON admissions/completion also require Idempotency-Key.
Listings accept limit 1-100 and an exclusive owned before UUID.
Errors include unsupported_source, unsafe_source, integrity_failed, upload_busy,
incomplete_upload, duration_exceeded, plan_duration_exceeded, insufficient_capacity
(507), queue_full/ingestion_limit/processing_limit (429), and Phase 2 credit errors.
Completion of ingestion does not imply completion of a requested clip deliverable.

Phase 4 adds owner-scoped GET /videos/{id}/transcript and
GET /videos/{id}/suggestions; optional job_id selects an owned PROCESS job.
Suggestions accepts limit 1..20. Configured processing advances to
SUGGESTIONS_READY, with rendered=false and no credit settlement. Disabled AI
stays WAITING_ENGINE. See [AI_HANDOFF.md](AI_HANDOFF.md) for DTOs, paid-call
protection, caching, cancellation, privacy, configuration and unrun live Gate 4.

JobView includes updated_at, stage, nullable progress_percent and nullable
estimated_credits. Completed ingestion and verified rendering report 100 percent;
other states return null. Ingestion has zero credit cost. PROCESS reports its
persisted accepted reservation amount (null for a legacy checkpoint without that value), independent
of later catalog changes. See INGESTION_HANDOFF.md for exact stage semantics.
GenerateInput accepts quote_id; the path supplies video_id. Both generation routes
use the same normalized payload/key and cannot create duplicate reservations.

## Phase 6 prepaid billing

See [PAKISTAN_PAYMENTS.md](PAKISTAN_PAYMENTS.md) for the signed mock protocol,
merchant documentation boundary, late/reversed states and manual sandbox steps.
Default is disabled; production rejects mock/live enablement. JazzCash is a named
disabled adapter, with no real checkout or verified merchant integration.

| Method/path under /api/v1 | Contract |
|---|---|
| POST /billing/orders | OrderInput{price_version_id} -> 201 CheckoutView; owner, Origin/CSRF, Idempotency-Key; null checkout_url, explicit sandbox |
| GET /billing/orders/{order_id} | Owner OrderView, integer PKR paisa/credits, expiry/state; browser query parameters are never authoritative |
| GET /billing/history | Owner OrderPage{items,next_cursor}; limit 1..100, exclusive owned UUID cursor |
| POST /billing/webhooks/{provider} | Signed 16 KiB JSON ingress; mock timestamp/signature headers; exact amount/currency/reference; no browser cookie/CSRF dependency |
| GET /admin/payments | Audited server-RBAC StaffOrderView list, bounded limit/cursor, refund exposure |
| POST /admin/payments/{order_id}/reconcile | StaffAction{reason,accept_late=false}, Origin/CSRF/key; independent verified query only, no evidence grants zero |
| POST /admin/payments/{order_id}/refund | RefundInput{reason}, Origin/CSRF/key; durable UNKNOWN/CONFIRMED RefundRequestView; no blind retry |

Purchase terms are pinned to the current audited price version at creation; later
price changes cannot mutate the order. Paid access is prepaid 30 days; top-ups do
not override timed access. Free or zero-price/allowance versions cannot be bought.
No customer-selected amount/currency/credits/provider/return URL is accepted.
Order keys and provider event IDs reject changed payload reuse. Payment transition,
entitlement and GRANT are one locked PostgreSQL transaction. Failed/pending events
cannot undo paid state. A verified pre-expiry payment may arrive late; post-expiry
payments enter REVIEW unless accepted via reasoned staff query. Full reversal
revokes entitlement and recovers available credits once; spent/held exposure is
recorded and access disabled, without negative balances. Partial refunds, recurring
billing and customer automatic-refund policy are absent. New errors include
payments_disabled (503), invalid_payment_signature (401), invalid_payment_event
(422), payment_mismatch, price_stale, price_unavailable, order_not_paid and
refund_already_requested (409), plus existing idempotency/ownership errors.

## Phase 7 private operations

`GET /api/v1/admin/operations?start=2026-10-01T00:00:00Z&end=2026-11-01T00:00:00Z`
returns the implemented OperationReport in openapi.json. Server admin/RBAC is
required; each successful read appends an immutable audit. Dates must be aware
UTC, start at calendar month midnight and end later within that same month.
Decimal USD/economics are strings; PKR paisa/credits/usage/storage are integers.
Optional economics stays null until private versioned assumptions are configured.
See MONITORING_SECURITY.md for field semantics and limitations; this is an
operations estimate, not an invoice or verified profit. Invalid period/policy422.
Phase 7 customer proxy blocks all /admin paths; private listener still enforces
the same cookie/RBAC/CSRF contracts. No privacy-erasure public route exists.
Deploy profile disables AI/payments/email/Google/trial grants and all webhooks.

`POST /api/v1/jobs/quote-preview` is a private-staging-only, authenticated/CSRF
read-only preview. Response: `preview_only=true`, `processing_enabled=false`,
`pricing_status=unconfigured|unapproved|configured`, nullable `price_version_id`
and `credits`, and echoed validated `request`. No quote ID is issued; this response
cannot reserve credits or dispatch work. Missing/unapproved pricing is represented
by null credits, never invented pricing. Public production returns 404. Private
preview requires all AI/payment switches off and the spending breaker closed.
`POST /jobs/quote` and all commercial admission checks retain their existing contract.
