# API handoff — Phase 1

The implemented contract is [openapi.json](openapi.json), generated with
`uv run python scripts/export_openapi.py` from `zoclip.main.create_app` without
connecting to a provider or database. No future endpoints are included.
See [AUTH_HANDOFF.md](AUTH_HANDOFF.md) for request flow, cookies, CORS/CSRF,
disabled-service behavior and development email instructions.

Schemas: Me, Message, LoginResponse, CsrfResponse, SessionView, AuditView/AuditPage
and RFC7807-like Problem. Error content type is application/problem+json; validation
errors are sanitized rather than echoing passwords/tokens. UUIDs identify users and
sessions. UTC timestamps are generated by the application; database timezone should
be UTC. GET /me ignores any caller-supplied user ID and returns the session owner.
Foreign resource lookups use ownership in the SQL predicate and return 404.

Production disables interactive docs and OpenAPI HTTP routes. Keep generated
contract artifacts available privately to frontend developers. No frontend or
v0 production handoff beyond auth is claimed in this phase. PATCH /me is deferred
because no editable profile fields were specified; email/password/role changes are
not exposed as an unrestricted profile update.
